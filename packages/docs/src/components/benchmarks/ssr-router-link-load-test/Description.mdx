Methodology: [SSR Router Link Load Test](/methodology/#ssr-router-link-load-test).

Measures server throughput and response latency as concurrent connections increase, with each request rendering a 1,000-row table using framework router link components.

Compare it with the [plain link load test](/run-time/#ssr-load-test) to see how these components affect server rendering performance. These tests make HTTP requests only; they do not measure browser navigation or prefetching.

Frameworks without a router link component are excluded.

DevTime benchmarks run using each meta-frameworks starter-* package.

Each starter project is set up using a meta-frameworks CLI using all default or recommended options. If no CLI is available, we follow the official documentation for the recommended setup.

You can find more details on the [setups in the methodology](http:///methodology/#project-setups).

For the base setup benchmarks themselves in the DevTime section, see the [default setup](http:///methodology/#default-benchmark-setup) on the methodology page.

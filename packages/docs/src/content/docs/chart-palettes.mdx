Compare all 26 [Tailwind default colour families](https://tailwindcss.com/docs/colors) using the same interaction breakdown chart. Use the site's theme selector to compare light and dark mode.

Each chart uses shade **300 for input delay**, **500 for processing duration**, and **700 for presentation delay**. Borders are removed, matching the current interaction charts.

These are illustrative timings, not benchmark results. Every chart repeats the same values so only the colours change. This page is a visual comparison, not an accessibility certification of these palettes.

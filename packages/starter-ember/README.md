# starter-ember

An Ember application created with `ember.nvp`.

## Getting Started

### Prerequisites

- Node.js >= 24
- pnpm

### Installation

```sh
pnpm install
```

### Development

To start the local development server:

```sh
pnpm dev
```

### Production build

To build the app, then serve the build on `$PORT` (default 4200):

```sh
pnpm build
pnpm preview
```
